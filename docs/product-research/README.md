## 반영한 차이

HCM-35T는 꺾인 어깨의 전면판, 8방향 슬라이드, 두 대각 스피너 부착 구성, 우측 CNC 조작반, 하부 통풍구와 케이블을 재구성했습니다. 초기 v3에서는 무캠식이라는 설명을 원형 구동부의 비회전으로 잘못 해석했습니다. v6에서는 CSX-35/CSX-20의 실제 영상에서 확인한 회전 원판·편심 핀·연결봉 구조를 추가 반영했습니다. 고정 베어링 몸체와 회전 원판을 분리하고 8개 슬라이드에 연동합니다. 정확한 HCM 내부 규격은 미확인입니다. [추가 영상과 정정 근거](../rotation-research/README.md)를 참고하세요.

HAM-10T는 상부 12시 방향 슬라이드 대신 독립 4축 툴 체인저와 XYZ 이동을 지원한다고 명시되어 있습니다. 상세 사진의 열린 상부 커버와 우측 조작반, 사진에서 확인되는 하단/측면 다섯 슬라이드, 중앙 가이드와 상부 헤드를 각각 구성했습니다. 커버는 정지된 전시 자세이며 안전 인터록 동작을 재현하지 않습니다.

사양은 게시된 표를 전사했습니다. HCM-35T는 선경 1.0–4.0 mm, 최대 이송률 90m/min, 스트로크 130mm, 롤러 6개, 4,000kg, 게시 치수 210×200×195cm입니다. HAM-10T는 선경 0.4–1.0mm, 최대 이송률 160m/min, 스트로크 80mm, 롤러 4개, 850kg, 140×120×160cm입니다. 두 제품 모두 본문은 기본 12축/최대 16축을 명시합니다. 현재 판매 사양은 제조사 확인이 필요합니다.

후면 롤러 배치, 내부 전달 기구, 제어 화면, 공구별 스트로크와 위상, 코일 예시 형상은 교육용 단순화입니다. 시연은 실제 생산 속도, 특정 제품의 공구 세팅이나 정밀 치수를 보증하지 않습니다. 원본 영상과 3D 모델이 같은 스프링을 같은 타이밍으로 생산한다고 주장하지 않습니다.

## 이전 v3 검증 결과 (최신은 [검증 기록](../verification.md))

- [HCM 원본과 모델 비교](hcm-comparison.png), [HAM 원본과 모델 비교](ham-comparison.png) 렌더 검토.
- HCM 92노드/68메시/1219.2KiB, HAM 76노드/57메시/842.3KiB. 단일 장면, 내장 재질, 외부 텍스처 없음.
- `check-motion.mjs`: HCM 독립 슬라이드 8개/롤러 6개, HAM 슬라이드 5개/툴 체인저 1개/롤러 4개, 두 모델의 코일 8턴 검증.
- 선재 굵기 불변, 코일 권수 증가, 슬라이드 비회전, 반복 자세 안정성, 4단계/분해·조립 복귀 및 데스크톱/모바일 정면·사선 카메라 경계 검사 통과.
- gstack: 모델 선택 시 모델명·사양·사진·포스터·출처·영상 URL 갱신, URL 직접 접근/새로고침/뒤로 가기, 업체 전환 후 제품 선택 유지 확인.
- 영상 모달의 영상 전환과 링크, 임베드 썸네일 표시, 모달 종료 시 iframe 제거 확인. 원본 YouTube 페이지에서는 실제 가공 장면을 확인했으며 앱 안의 임베드 재생 완료는 별도 검증하지 않았습니다.
- 375px 페이지 및 비교 모달 가로 넘침 없음.
- `npm run build` 통과. Three.js core 청크 크기 경고는 남습니다.

자동화 브라우저는 여전히 WebGL 컨텍스트를 만들지 못합니다. UI 스크린샷의 모델은 표시된 정지 렌더 대체 화면이며 실시간 회전·GPU 동작·실기기 FPS 검증을 의미하지 않습니다. 생산 배포는 수행하지 않았습니다.
