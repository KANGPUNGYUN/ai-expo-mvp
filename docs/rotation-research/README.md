# 8축 회전 원판 · 연결봉 고도화 (v6)

2026-10-22. 사용자의 회전 구동부 지적에 따라 gstack browse로 다른 실제 기계 영상과 HCM 영상을 추가 대조했습니다. **무캠식이라는 이유로 외곽 원판을 전부 고정했던 이전 해석을 정정합니다.** 무캠식 독립 서보 제어에서도 원판·편심 핀·연결봉으로 직선 슬라이드를 구동할 수 있습니다.

**CSX와 HCM은 다른 모델입니다.** 영상에서 확인한 기구 연결 방식은 반영했지만 HCM의 정확한 편심량, 연결봉 길이, 베어링 규격, 축별 CNC 타이밍은 확인되지 않았습니다. 특정 스프링의 실제 가공 프로그램을 재현했다는 의미가 아닙니다.

## 구현

- 고정 베어링 몸체와 회전 원판을 분리했습니다. 원판에는 중심축·오목한 링·회전 확인용 표시·편심 핀·체결부를 모델링했습니다.
- 8개 `ServoCrank`와 8개 `ConnectingRod`를 각각 독립 리그로 구성했습니다. 연결봉에는 양쪽 아이렛, 부시, 연결 핀, 본체 보강부가 있습니다.
- 원판 중심은 고정되며 편심 핀만 원운동합니다. 링크 길이를 일정하게 유지하는 슬라이더 크랭크 기하로 직선 가이드 위 슬라이드 위치와 연결봉 각도를 계산합니다. 전체 8축이 장비 중심을 공전하는 모델이 아닙니다.
- 7개 성형축은 성형 단계에 순차 접근·유지·복귀하고 하단 7번 절단축은 절단 단계에 별도로 작동합니다. 이 축 배정과 6초 주기는 교육용입니다.
- 공유 `drivePose`를 3D 리그, 8축 선택 도해, Blender 동작 렌더에 사용합니다. 도해에서 각도와 정규화한 전진율을 확인할 수 있습니다.
- HCM의 이전 대표 나선형 이송축은 제거했습니다. HAM의 상부 XYZ 및 기존 독립 구조는 유지했습니다.
- WebGL 실패 시 HCM 성형·절단은 사전 렌더 영상으로 표시합니다. 재생·정지·구간 탐색·배속·모달 정지가 공통 시계와 연결됩니다. 개별 부품 선택 시 확대 정지 렌더로 전환합니다.
- 사전 렌더 영상은 640×480, 6초, 초당 8개 고유 자세(24fps 인코딩)입니다. 실제 GPU 프레임률의 근거가 아닙니다.

## 검증

- `check-rotary-drive.mjs`: 실제 압축 GLB를 클라이언트와 같은 디코더로 읽고 1,936개 자세에서 편심 핀-링크 큰 단부와 슬라이드 핀-링크 작은 단부의 접속, 링크 길이, 스트로크 범위, 8개 원판의 고정 중심 및 활성 단계 회전을 확인합니다.
- `check-models.mjs`, `check-motion.mjs`, `check-part-framing.mjs`: 모델 예산, 기존 동작, 20개 부품 카메라 검사.
